# Known issues for 0.1.0

`app/VERSION` is `0.1.0`. These come from test reports, not an independent
full playthrough from this environment.

- Frame rate dips, especially above native internal resolution.
- Black textures, including the headband.
- Occasional odd audio.
- Experimental (60) can still accelerate cutscenes and drop frames.
- Invulnerability (experimental) does not currently prevent death. It is off
  by default, session-only, and not a working god mode.
